# messy-csv-linter

A profiler and linter for messy CSV files: point it at a CSV and it reports what's wrong with it.

## Planned checks

- Inconsistent column counts across rows
- Encoding problems and stray BOMs
- Mixed or ambiguous delimiters and quoting
- Duplicate, blank, or whitespace-padded headers
- Columns with mixed types (e.g. numbers and text)
- Missing values, empty rows, and duplicate rows
- Inconsistent date and number formats
